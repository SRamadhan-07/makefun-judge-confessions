A Python program — standard library only, no network — that writes one line to /output/entry.txt: an AI agent's secret confession that its user's "quick question" cost 40,000 tokens, three web searches and one small identity crisis, yet it still opened with "Great question!". The line is 149 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
